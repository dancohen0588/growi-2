Évolutions GardenPalette + palette.ts La section "Plantes" n'est plus hardcodée dans palette.ts :
• GardenPaletteSection reçoit une prop dynamicPlants?: PlantCatalog[]
• Chargement via Server Action getCatalogByCategory(cat) avec pagination
• Dropdown catégorie = enum category de la DB
• Input de recherche filtre côté client (debounce 200ms)
• Thumbnail : imageUrl → fallback emoji
• Le drag payload reste identique : { type:'plante', emoji, label, … }
